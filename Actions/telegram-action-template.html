Filtro de condição recomendado
Condition type: Event tag value Tag name: notificar Operator: equals Value: telegram
Com esse filtro, somente triggers com notificar=telegram disparam mensagem. Triggers com notificar=nao ficam apenas no Zabbix (DyingGasp, Queda Parcial, etc.).

Para ativar notificação em DyingGasp: altere a tag notificar=telegram no trigger prototype do template.
