## Brand Identity
- **Name**: Netstream Topology Panel
- **Tagline**: "Criando as melhores soluções de monitoramento de rede"
- **Primary color**: #00e5c8 (teal/cyan)
- **Accent**: #ff6b35 (orange)

## Key Product Info
- Plugin for Grafana (v10+)
- Supports Zabbix, Prometheus, InfluxDB datasources
- Current version: v2.13.0
- 87+ features, 40+ integrated icons, 6 visual themes
- Drag & drop topology editor
- Real-time metrics, visual alerts, lanes/layers
- Zero external dependencies
- Used by ISPs, data centers, corporate networks, NOC teams
